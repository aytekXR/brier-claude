Product UI

The rating-agency aesthetic, operationalized. Clinical, typographic, data-forward surfaces where the leaderboard is the brand and every score is one click from its receipt. All mock-ups below use the live tokens.

4.1 · Dashboard & layout

The leaderboard is the home screen

Brier has no “dashboard” in the personal-analytics sense — the public surface is a ranked table. Layout principle: a single authoritative column of data, framed by hairlines and a quiet top nav, with the methodology version pinned in view at all times.

4.2 · Workflows

Workflows, mapped to the real product

The brief’s generic “trading-journal” workflows don’t exist in Brier — it never journals the reader’s trades. Each is re-mapped to Brier’s actual surface, with its governing UI principle.

“Journal mgmt” → Analyst coverage registry

Coverage & ingestion

Internal console to add channels, set jurisdiction flags, and watch ingestion freshness. Stale >48h raises a flag, never a silent gap.

“Trade review” → Claim QA queue

Extraction review

Transcript span beside structured claim; approve / correct / void. Reviewer ID logged. Nothing below confidence threshold publishes unreviewed.

“Performance analytics” → FAS breakdown

Accuracy analytics

Four component bars + outcome chips + trend. Every number links to the ledger; nothing is a black box.

“Trade tagging” → Claim structuring

Claim tags

Asset, direction, magnitude, horizon, stated confidence, conditionality, specificity class — the falsifiable schema, controlled vocabulary.

“Psych tracking” → Calibration dashboard

Calibration (creator)

Private creator view: confidence-vs-outcome reliability curve and exactly which habits move the score. Never pay-to-improve.

“AI insights” → Pipeline confidence

Extraction insights

Model/prompt versions, confidence per claim, dedup clusters, sponsor-segment flags — surfaced for QA, never sold as “signals.”

“Reporting” → Methodology & corrections

Public reporting

Versioned methodology page, public corrections log, weekly Receipts digest, annual “State of Finfluencer Accuracy.”

“Goal tracking” → Rank & dispute SLA

Rank & disputes

Creators track rank movement; disputes carry a visible 7-day SLA countdown and a tracked ticket ID.

4.3 · Component library

Components & interaction rules

Buttons

Hierarchy · navy=primary action, blue=verify/interactive, ghost=secondary

3 px radius, 13 ms transitions, no gradient fills. One primary action per view. Destructive (void) actions use the error color and require confirmation.

Mono placeholder for query-shaped fields. Focus = 3 px Brier-Blue halo. Labels are uppercase mono micro-caps.
